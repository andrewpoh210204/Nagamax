# Dealer Redemptions

### Purpose
Dealer Redemptions allow dealers to redeem accumulated dealer points for rewards.

### Create a dealer redemption
1. Go to **Dealer → Dealer Redemptions**.
2. Click **New Dealer Redemption**.
3. Select the dealer.
4. Select a redemption item.
5. Enter quantity.
6. Review total points used.
7. Submit the redemption request.

### Redemption status
- New requests are submitted as **Pending**.
- Admin or Super Admin will approve or reject the request.
