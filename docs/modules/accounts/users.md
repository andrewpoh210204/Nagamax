# Users

### Purpose
Users represent end-users of the system who earn points, register vehicles, and perform redemptions.

### View users
1. Go to **Accounts → Users**.
2. Use search to find users by name, email, or phone.
3. View user details.

### Create a user
1. Click **New User**.
2. Enter:
   - Name
   - Phone
   - Email
   - Password
3. Set user status to **Active** if applicable.
4. Click **Create**.
