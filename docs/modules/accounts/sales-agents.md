# Sales Agents

### Purpose
Sales Agents are assigned to dealers and are used for sales tracking and reporting.

### View sales agents
1. Go to **Accounts → Sales Agents**.
2. Review:
   - Sales code
   - Name
   - Email
   - Active status

### Create a sales agent
1. Click **New Sales Agent**.
2. Enter:
   - Sales code
   - Name
   - Email
   - Password
3. Set active status.
4. Click **Create**.
