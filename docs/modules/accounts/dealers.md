# Dealers

### Purpose
Dealers represent registered business partners that place sales orders and earn dealer points.

### View dealers
1. Go to **Accounts → Dealers**.
2. Use search to locate dealers.
3. View dealer details:
   - Dealer code
   - Name
   - Email
   - Phone
   - Active status

### Manage dealers
- Edit dealer details as required.
- Activate or deactivate dealer accounts.
