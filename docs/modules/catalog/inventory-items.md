# Inventory Items

### Purpose
Inventory Items define products available for sales, service records, and warranties.

### View inventory items
1. Go to **Catalog → Inventory Items**.
2. Use search, filters, or column toggles to locate items.
3. View item details:
   - Item code
   - Description
   - List price
   - Stock quantity
   - Dealer points
   - User points
   - Warranty days
   - Category
   - Active status

### Bulk actions
Inventory items support bulk actions:
- Set Active
- Set Inactive
- Bulk set category
- Bulk set warranty days
- Bulk edit selected items
