# Redemption Items

### Purpose
Redemption Items define rewards that dealers and users can redeem using points.

### View redemption items
1. Go to **Catalog → Redemption Items**.
2. Use search or filters to locate items.
3. View item details:
   - Category
   - Points required
   - User points required
   - Stock quantity
   - Active status

### Create a redemption item
1. Click **New Redemption Item**.
2. Select category.
3. Enter item name.
4. Enter:
   - Dealer points required
   - User points required
   - Stock quantity
5. Set item as active if applicable.
6. Click **Create**.
