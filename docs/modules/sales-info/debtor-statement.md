# Debtor Statement

### Purpose
Debtor Statement provides a transaction-based statement for a dealer within a selected date range.

### Generate a debtor statement
1. Go to **Sales Information → Debtor Statement**.
2. Select **Date From**.
3. Select **Date To**.
4. Select **Dealer**.
5. Click **Preview PDF** to view the statement.
6. Click **Export PDF** to download the statement.

This report is commonly used for dealer reconciliation and payment follow-up.
