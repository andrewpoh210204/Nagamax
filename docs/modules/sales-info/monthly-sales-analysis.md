# Monthly Sales Analysis

### Purpose
Monthly Sales Analysis summarizes sales performance over time, typically by sales agent.

### Generate a monthly sales analysis
1. Go to **Sales Information → Monthly Sales Analysis**.
2. Select **Date From**.
3. Select **Date To**.
4. Select **Sales Agent**.
5. Click **Load** to generate the report.

### What the report shows
**Summary**
- Sales agent name
- Agent description
- Total sales amount for the selected period

**Monthly breakdown**
- Sales amount grouped by month within the selected date range

This report is used to:
- Track sales trends
- Measure agent performance
- Compare monthly sales results
