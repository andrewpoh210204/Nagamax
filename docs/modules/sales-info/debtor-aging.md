# Debtor Aging

### Purpose
Debtor Aging shows outstanding balances for a dealer, grouped by aging periods. It helps monitor overdue invoices and manage credit exposure.

### Generate a debtor aging report
1. Go to **Sales Information → Debtor Aging**.
2. Select **Date**.
3. Select **Dealer**.
4. Click **Load** to generate the report.

### What the report shows
**Summary**
- Debtor number and company name  
- Sales agent  
- Contact details  
- Currency  
- Outstanding amounts by aging buckets:
  - Current
  - Month 1
  - Month 2
  - Month 3
  - Month 4
  - Month 5 and over
- Total overdue amount
- Total balance

**Details**
- Document number
- Document type
- Document date
- Due date
- Outstanding amount
- Aging days
- Credit term
