# Status

### Purpose
Status provides real-time visibility into system integrations and background jobs.

### View system status
1. Go to **System → Status**.
2. Review the status of system processes.

### Run system checks
- Click **Run** to execute individual processes.
- Click **Run All** to execute all system processes.

### Common system processes
- Dealer sync
- Invoice sync
- Item sync
- Outstanding balance sync
- Sales order sync
- Warranty status updates

Each process displays:
- Status
- Start and finish time
- Duration
- Result message
- Metadata
