# Sync Logs

### Purpose
Sync Logs provide a historical record of all system synchronization jobs.

### View sync logs
1. Go to **System → Sync Logs**.
2. Use search or filters to locate logs.
3. Review log details:
   - Sync type
   - Status
   - Start and finish time
   - Duration
   - Message

### View sync log details
1. Click **View** on a sync log entry.
2. Review detailed results and metadata for troubleshooting.
