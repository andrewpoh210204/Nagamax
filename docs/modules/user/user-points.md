# User Points

### Purpose
User Points track loyalty points earned by users through service records and other activities.

### View user points
1. Go to **User → User Points**.
2. Use search to locate a user.
3. View the user’s total points balance.

### Add or deduct points
1. Locate the user in the list.
2. Click **Add points** or **Deduct points**.
3. Enter the points adjustment and reason.
4. Save changes.

> Only Super Admin and Admin can adjust user points.
