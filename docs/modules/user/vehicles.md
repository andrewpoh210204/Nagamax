# Vehicles

### Purpose
Vehicles store vehicle information linked to users for warranty and service records.

### View vehicles
1. Go to **User → Vehicles**.
2. Use search to find vehicles by plate number or owner.
3. View vehicle details.

### Create a vehicle
1. Go to **User → Vehicles**.
2. Click **New Vehicle**.
3. Enter:
   - Plate number
   - Model
   - Year made
   - Owner name
   - Owner phone
4. Click **Create**.
