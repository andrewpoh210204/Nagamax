# User Point Transactions

### Purpose
User Point Transactions provide a complete audit trail of all user point changes.

### View user point transactions
1. Go to **User → User Point Transactions**.
2. Use search to filter by user or date.
3. Review transaction details:
   - Date and time
   - User
   - Description
   - Points added or deducted

This section is used for verification and dispute resolution.
