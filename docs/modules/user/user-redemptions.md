# User Redemptions

### Purpose
User Redemptions allow users to redeem accumulated points for rewards.

### View user redemptions
1. Go to **User → User Redemptions**.
2. Filter by status:
   - Pending
   - Approved
   - Rejected
3. View redemption details.

> End-users can create and view their own redemption requests.  
> Admin users approve or reject requests.
